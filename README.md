# Bible Reader content — GU-Gujarati

This repository contains the Bible Reader SD-card content for **GU-Gujarati**.

## Directory layout

- `text/GU-Gujarati/` — all Bible translations and their original nested folder structure.
- `audio/GU-Gujarati/` — audio Bible book folders and chapter MP3s.
- `gospel/GU-Gujarati/` — Gospel files, retaining original names such as `Gospel.txt` and `Gospel.mp3`.

Copy these folders into the root of the Bible Reader `SDCARD` staging directory.
Do not rename files or flatten directories: the firmware expects the original paths.
